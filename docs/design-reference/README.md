# design-reference — Captures d'écran de référence

Captures figées des écrans clés, pour référence rapide sans ouvrir de
navigateur. **La version interactive fait foi pour le comportement**
(hover, animations, transitions) — voir `keyli_dashboards_preview.html`
à la racine du paquet de documentation.

| Fichier | Écran | Rôle |
|---|---|---|
| `keyli_ecran_accueil.png` | Page d'accueil publique | Recherche, grille "Logements de Confiance", quartiers populaires |
| `keyli_dashboard_agence.png` | Dashboard Agence | Pipeline de leads, KPIs, performance équipe |
| `keyli_dashboard_proprietaire.png` | Dashboard Propriétaire | Stepper de vérification, mes biens, messages |
| `keyli_dashboard_chercheur.png` | Dashboard Chercheur | Recommandations, comparateur, tendances quartier |

Captures recadrées à la partie visible sans défilement (~900-1000px de
haut) et compressées — pour voir l'écran complet, ouvrir le fichier HTML
correspondant ou `keyli_dashboards_preview.html`.
